Robust Mediation Simulation

Robust Mediation Simulation Study

Built a Monte Carlo simulation framework in R to stress-test the ROBMED package across a 17-scenario grid varying sample size, binary vs. continuous predictors, mediator correlation, and outlier contamination. Showed that bad-leverage contamination collapses confidence-interval coverage from 95% to 6% while making mediator rankings appear more accurate — a failure mode invisible from point estimates alone. Calibrated a power curve from 140 simulated mediator conditions to forecast, in advance, which effects were detectable in the real 100-donor dataset and which were underpowered.

R Monte Carlo Simulation Mediation Analysis
